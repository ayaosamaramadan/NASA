## ✨ Features

| Feature | Description |
|---------|-------------|
| 🪐 **3D Solar System** | Fully interactive planets with realistic orbits, textures, and lighting |
| ☀️ **Sun Visualization** | Dynamic sun with bloom effects and post-processing |
| 🌌 **Galaxy Generator** | Procedurally generated galaxy background with stars |
| 🌍 **EPIC Earth Imagery** | Real-time Earth imagery from NASA's EPIC camera |
| 🌙 **Moon WMTS Mapping** | High-resolution Moon surface mapping using Cesium |
| 📸 **APOD Viewer** | NASA's Astronomy Picture of the Day with 3D projection |
| 🤖 **AI Chatbot** | Space assistant powered by Google Gemini API |
| 🎵 **Ambient Music** | Immersive space soundtrack with sound effects |
| 🖱️ **Custom Cursor** | Themed cursor for enhanced UX |

## 🌐 NASA APIs Used

- **APOD** - Astronomy Picture of the Day
- **NASA Image Library** - Search & retrieve space imagery
- **EPIC** - Earth Polychromatic Imaging Camera
- **Moon WMTS** - Lunar surface tiles
